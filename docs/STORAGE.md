# 压缩分包与增量格式

格式 3 沿用 `vaults/<设备>/snapshots/<ID>.json` 和最后写入的 `.sha256` 提交标记。内容位于 `packs/<压缩包SHA-256>.zip`；旧的 `objects/` 内容与旧快照保留，不原地转换或清理。

每个快照自含以下内容：

- `roots`、`entries`：完整目录、文件、链接、节点和权限/UID/GID/扩展属性，普通文件有整文件 SHA-256；大文件另有顺序分块引用。
- `blobs`：该快照需要的每个内容哈希，对应原始大小和分包哈希。
- `packs`：所有依赖分包的压缩大小与完整 `members` 索引。包内 ZIP 文件名仅为内容 SHA-256，不存设备绝对路径或权限。
- `packages`、`lsposed`、`environment` 等逻辑数据保持原语义，账号和 WebDAV 连接配置不进入快照。

新增内容先在本地稳定读取、哈希去重，再压缩；8 MiB 以上文件切成 8 MiB 内容块。每包最多 16 MiB 原始内容、1,024 个内容对象，ZIP 使用标准 Deflate level 1。4 MiB 以上的块独立成包，避免增量恢复下载与它混装的过期大块；从中部采样 32 KiB，压缩节省不足 5% 时使用 ZIP STORED，减少已压缩 APK 或随机二进制的处理成本。单次包 PUT 硬上限 24 MiB。包写入后按完整大小和 SHA-256 回读验证，全部成功才发布快照。重复内容只写一次；零长度文件也有正常对象。

增量从同设备最近一次已提交清单恢复引用，逐个依赖包 HEAD 核对大小，避免逐文件 HEAD。未变化内容不重传，删除只改逻辑清单。局部修改文件只上传变化的内容块。最新快照不再引用的历史内容可能在重新出现时重新打包；没有全历史全局去重或自动垃圾回收。包损坏但大小未变会在下载时被 SHA-256 拒绝；HEAD 不等同于全历史位腐巡检。

中断后不会留下已提交的不完整快照。尚未提交的完整包若下次组成相同，按内容地址复用；半写包会覆盖修复。源数据变化可能产生不被任何快照引用的包，当前保留这些包。提交前不会删除旧快照。

恢复预检估算下载的压缩大小，以及内容缓存、分块拼接、恢复文件与回退空间。正式 `Engine.stage` 对新包和旧对象最多 4 路并行下载，使用临时文件、校验后改名；ZIP 条目必须属于完整成员索引，拒绝未知名、重复名、条目缺失、超限解压、哈希或大小不符。成员写到哈希命名的私有缓存，不直接解压到 Android 目标。所有内容校验完成后才生成正式恢复任务；恢复与回退日志、两次重启时序不变。

重试检查本地对象大小及 SHA-256，只下载缺失内容需要的包；已完整下载的包也可直接用于重试。块拼接后再次校验整个文件 SHA-256。文件元数据由原有恢复流程设置，应用根目录与 cache/code_cache 的 Android inode 保护保持不变。

单 ZIP 导出包含原始快照 JSON、对应提交标记，以及其全部依赖 `packs/`（格式 3）或 `objects/`（格式 1/2）。外层 ZIP 不重复压缩已有包。解压到独立 WebDAV 根目录即可发现和恢复同一快照；不需要原 NAS、历史快照链或本机索引。导出文件在手机私有 `exports/` 下，清理恢复暂存不会删除它。

格式 1/2 继续只读兼容。写入旧对象格式的内部 `legacyObjects` 配置只供兼容性回归使用，WebUI 不提供此选项；正常配置始终创建格式 3。

## beta.6 双入口与库身份

配置使用 `externalOrigin`、`internalOrigin` 和唯一的 `path`。origin 只有协议、主机和可选端口；path 是未编码的绝对目录，例如 `/backup/`。中文、空格和字面百分号在组合 URL 时编码一次。拒绝凭据嵌入地址、查询参数、片段、路径穿越、编码的点和分隔符。HTTP 需要显式开启，TLS 保持系统证书验证。

`wifiNames` 是最多 64 个名称的数组，按 UTF-8 1～32 字节验证，保留首尾空格，精确匹配并去重。通过 Root 的 `cmd wifi status` 读取已连接主接口；双 Wi-Fi 优先明确的主接口，无法可靠识别时使用默认地址。未匹配时不会向内网地址发送凭据。名称匹配只是选择条件，之后仍需 WebDAV 探测。

每次操作先做 Depth 0 PROPFIND 和库标识读取。网络连接失败可回退外网，HTTP 401/403/5xx、TLS、重定向与标识错误不回退。一次操作固定一个 Dav 实例，任务途中不会混用两个入口。

共用目录新增 `.nasbackup-repository.json`，内容为 `format: 1` 和随机 UUID。没有标识的既有备份库使用条件 PUT（`If-None-Match: *`）初始化并回读，不转换或删除原快照、分包。手机以共用路径的哈希在私有 `repositories/` 绑定该 UUID；切换入口时必须读到同一标识，提交快照前再次检查。标识不是登录凭据、签名或客户端加密。

当前入口先验证；首次选择内网时，若外网可达则核对同库。外网网络不可达可以暂缓核验；未知 Wi-Fi 下不主动探测内网，等内网实际被选择时再核对。已绑定入口缺少标识、UUID 改变或指向另一库时停止；不要手动删除或修改标识。两入口都指向新空库但并不共享存储时，也不会自动向另一入口复制标识以掩盖配置错误。

库绑定按共用路径保存。若有意迁移到同路径下的另一份独立备份库，应先核实迁移关系，再由 Root 管理员处理本机绑定；WebUI 没有自动解除身份保护的开关。导出 ZIP 不携带原目录标识，解压到新目录后按新库初始化，新手机没有原库绑定即可使用。

状态轮询通过只读脱敏缓存返回配置、任务和恢复阶段。缓存文件 Root 私有、原子替换，配置字节哈希和版本不符时回到 Java 重建；恢复日志变化时更新脱敏视图。不返回密码、恢复日志中的本机路径或 APK 身份。原始设置保存在手机私有配置，既不进入快照也不随安装包发布。
