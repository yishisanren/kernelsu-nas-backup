## 真实数据完整备份补测

用户明确授权后，现用手机的模块与配置经 USB 回环上传至本机私有临时 WebDAV，未发送到互联网。首轮途中手机断开并重启，留下一个半写对象，未发布不完整快照。重连、解锁机主及系统分身后重试，复用已有内容，仅补传 61 个对象、379,062,791 字节，成功生成完整快照。半写对象已修复。

两份完整快照和 20,657 个存储对象全部通过 SHA-256 校验；目录与文件私有权限检查通过。首份快照含 29,529 个条目、22,458 个普通文件，逻辑文件总量 3,663,877,031 字节。第二轮复用 22,442 个未变化文件，仅上传 15 个对象、13,484,367 字节；变化来自运行中的模块及应用配置。另有一个新快照引用的内容对象复用了中断尝试已上传的对象，因此“相对上一快照新增对象数”不等于实际新增上传数。

覆盖 23 个 KernelSU 模块、12 份同版本原 ZIP、8 个外部配置根，以及 29 个不同 LSPosed 应用在两个用户下的 31 份安装/配置记录。LSPosed 数据库保留 31 条模块记录、32 条状态、103 条作用域和 352 条模块配置。数据库临时重建的六表、521 条记录已核对；随后发现其中 2 条模块记录对应应用已卸载，没有可备份 APK，原恢复逻辑会因此报错。

最终修复版已通过 51 项 Android 隔离回归及 12 项 WebUI 检查。随后使用已生成的真实快照验证最终数据库恢复代码：按实际备份的 29 个不同应用重映射 APK 路径，2 条已卸载残留保持禁用；6 张表、521 条记录与预期逐项相同，BLOB 和作用域完整保留。当前手机的数据库未被替换。真实文件增量采集发生在该恢复修复之前；最终恢复实现已针对真实快照重测，未额外重复整份真实采集。

验证结束后，Mac 私有临时备份目录、回环 WebDAV 服务、手机测试目录和测试 APK、USB reverse 映射均已清理并核对。交付记录仅保存统计与检查结果，不含真实应用配置、APK 或备份对象。

记录见 [中断记录](evidence/real-backup-interruption.json)、[两轮运行统计](evidence/real-backup-runs.json)、[完整性和增量核验](evidence/real-backup-audit.json)、[真实数据库重建](evidence/real-lsposed-roundtrip.json) 和 [清理结果](evidence/real-cleanup.json)。

## 验证中修复的问题

- ColorOS 的 app_process 缺少默认 SQLite 初始化状态：改为显式指定同步模式，真机读写测试通过。
- 当前 LSPosed 分支与上游三表结构不同：适配真机六表及版本 101，保留配置 BLOB、按用户启用状态和作用域。
- Android 的 Files.getFileStore 不可用：改用 Android 支持的可用空间查询。
- 当前系统不支持 `cmd user is-user-unlocked`：改用实测可用的 ActivityManager 用户状态接口，锁定用户的加密配置不再允许被静默跳过。
- 真实配置范围存在虚拟终端设备节点和 runtime socket：保留受支持节点，排除运行时 socket。
- 避免修改现有父目录权限、路径归一化别名、安装半成品采集，以及 APK 跨用户共享版本的意外覆盖。
- 恢复时重建 NoMount 入口，分阶段恢复 LSPosed 启用状态，避免在应用数据尚未就绪时加载模块。
- 已卸载应用仍有 LSPosed 残留记录，原恢复代码要求所有记录都有 APK，导致准备恢复失败：改为保留这些配置和作用域并保持禁用，预检明确提示。
- 旧版 LSPosed 三表结构使用 `group` 保留字字段：改为对白名单字段名引用、对值参数化绑定，旧版夹具往返验证通过。
- 真实 NAS 前置 Cloudflare 给 HTML 对象注入脚本，普通 GET 返回内容从 14,550 字节变为 15,279 字节；完整字节范围 GET 返回原始内容且哈希一致。下载改为请求完整范围，并严格检查 206 Content-Range、总大小和 SHA-256；未修改 NAS 配置。见 [诊断记录](evidence/nas-html-proxy-diagnosis.json)。
- 真实 NAS 网关对大文件 PUT 返回 HTTP 413：新内容超过 32 MiB 时按 8 MiB 分块上传，保留整文件 SHA-256 和有序分块清单；恢复时同时验证块与整文件。已有完整对象继续复用，不重复上传。

## 复现

```sh
export JAVA_HOME=/path/to/jdk21
export ANDROID_HOME=/path/to/android-sdk
python3 scripts/verify_device.py --serial YOUR_ADB_SERIAL
python3 scripts/verify_package.py
python3 scripts/package_source.py
```

验证脚本只使用专用测试目录、USB 回环测试服务和专用测试 APK。测试入口与发布 dex 分开；源码包不含真实模块安装包、真实应用配置、NAS 密码或手机备份内容。
